# 🇸🇾 بوت سحب إعلانات المجموعات بالمتصفح المرئي (سوريا)

بوت ذكي ومؤتمت بلغة Python مخصص لسحب الإعلانات من مجموعات التواصل الاجتماعي وصفحات الويب عبر متصفح مرئي حقيقي (Chromium) مع فلترة دقيقة تستخرج إعلانات سوريا فقط المحتوية على أرقام هواتف وتصديرها بصيغة `JSON`.

---

## ✨ المميزات الرئيسية
1. **متصفح مرئي حقيقي (Headed Browser)**: يفتح المتصفح أمام عينيك مباشرة لمتابعة التمرير وسحب البيانات بدقة.
2. **حفظ جلسة المتصفح (Persistent Session)**: يحتفظ بتسجيل الدخول والكوكيز في مجلد `browser_session/` حتى لا تضطر لتسجيل الدخول في كل مرة.
3. **فلترة سورية حصرية**:
   - **الشرط الأول (في سوريا)**: التحقق التلقائي من الكلمات الدلالية والمناطق والمحافظات السورية (دمشق، حلب، حمص، حماة، اللاذقية، طرطوس، درعا، السويداء، إدلب، دير الزور، الحسكة، الرقة، إلخ...).
   - **الشرط الثاني (رقم سوري)**: استخراج أرقام الهواتف السورية بجميع صيغها:
     - المحلية: `093...`, `094...`, `095...`, `096...`, `098...`, `099...`
     - الدولية: `+9639...` أو `009639...`
     - الأرقام المكتوبة بالأرقام العربية/المشرقية (`٠١٢٣٤٥٦٧٨٩`)
4. **تصدير كامل للبيانات في ملف JSON**:
   - رابط الإعلان (`ad_url`)
   - أرقام الهواتف (`phone_numbers`)
   - نص ووصف الإعلان كاملاً مع توسيع "عرض المزيد" (`description`)
   - روابط الصور المرفقة عالية الجودة (`images`)
   - المنطقة المكتشفة (`location_detected`)
   - وقت السحب (`extracted_at`)

---

## 🚀 طريقة التشغيل

### الطريقة 1: التشغيل المباشر السريع (ويندوز)
- اضغط نقراً مزدوجاً على الملف `run.bat`.

### الطريقة 2: عبر موجه الأوامر (Terminal)
```bash
py main.py
```

---

## 📋 كيفية إضافة روابط المجموعات

يمكنك تمرير الروابط بإحدى طريقتين:
1. **عبر ملف `groups.txt`**: ضع روابط المجموعات في ملف `groups.txt` (رابط واحد لكل سطر).
2. **الإدخال التفاعلي**: عند تشغيل `main.py`، سيسألك البرنامج عن إدخال روابط المجموعات مباشرة من الطرفية.
